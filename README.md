# AYHAJAFCMD

This repository keeps the original projects in `AYHAJAFCMD-V1/` and the new terminal browser in `V2/`.

- `AYHAJAFCMD-V1/SocialCMD/`: original social-site terminal browser
- `AYHAJAFCMD-V1/YoutubePlayerCMD/`: original terminal YouTube viewer
- `V2/`: fresh Playwright Chromium browser, DuckDuckGo search, persistent isolated profile, and adjustable half-block pixel rendering

Start V2 on Windows by running `V2/SocialCMDV2.bat`. See [V2/README.md](V2/README.md) for commands and setup. The legacy projects retain their own README files and launchers under `AYHAJAFCMD-V1/`.
